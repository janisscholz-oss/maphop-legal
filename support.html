MapHop Support

Last updated: 21 September 2026

MapHop is a Safari Web Extension that opens supported Google Maps links in Apple Maps. Link handling is on-device and no account is required.

Common questions

  • Enable MapHop: In iOS Settings, open Apps → Safari → Extensions, select MapHop, and allow the extension. The exact labels can vary by iOS version.
  • Use MapHop: With the extension enabled, tap a supported map link in Safari. MapHop hands it off to Apple Maps. Short map links are supported when Safari exposes their destination.
  • Safari does not hand off: Confirm MapHop is enabled for the current website and that Safari has permission to use the extension. Reopen the link after changing the setting.
  • Apple Maps is not installed: Install or restore Apple Maps from the App Store, then try the link again.
